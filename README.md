# 🗺️ CleanMap — Community Waste Reporting App

CleanMap is a community-driven platform that helps citizens report garbage spots, track cleanup progress, and coordinate volunteers in real time. The goal is to encourage cleaner neighborhoods through easy reporting and transparent monitoring.

## 🚀 Features

- 📍 Report waste locations with geolocation support
- 📸 Upload images of garbage spots
- ⚠️ Assign severity levels to reported issues
- 🗺️ Interactive map view with color-coded markers
- 📊 Dashboard showing waste reporting statistics
- 🔄 Real-time report updates
- 🔍 Filter and sort reports
- 👥 Volunteer coordination and cleanup tracking
- 🌙 Responsive dark-mode interface

## 🎯 How It Works

1. Users report garbage locations using the reporting form.
2. The report includes location details, severity level, and optional images.
3. Reports are displayed on an interactive map.
4. Community members and volunteers can track cleanup activities.
5. Dashboard statistics provide insights into reported and resolved issues.
